Platform Features

Everything a Debate Platform Needs

👍👎

Support / Against Voting

Binary structured voting keeps every debate focused. Users pick a side and their vote is tallied in real-time, updating the live support percentage instantly.

🤖

AI Toxicity Moderation

Every comment is evaluated by an AI model before it goes live. Toxicity scores, stance detection, and confidence ratings are logged per comment. Flagged content shows a content warning that users must click to reveal.

📊

Real-Time Vote Tallies

Live vote counts, percentage splits, and comment counts update as users participate. The circular progress indicator always shows the current Support vs Against ratio.

🧵

Structured Debate Threads

Support arguments and Against arguments live in separate columns, preventing the cross-talk that makes most comment sections unreadable. Full view and split view layouts available.

🔍

Explore Feed

Browse all active debates in a card-based grid with thumbnail images, vote counts, and comment splits. Infinite scroll keeps the feed fresh. Share any debate directly from the card.

🏅

User Credibility Score

Users build reputation through civil, substantive arguments. The admin dashboard surfaces stance accuracy, toxicity scores, and comment activity per user for moderation decisions.

🌙

Dark Mode Interface

TrendTalk ships with a polished dark UI optimised for night reading — a necessity for debates that run into the early hours.

📱

Mobile-First Design

Debate feed, voting, and comment posting are all thumb-friendly on mobile. Available as a Progressive Web App and in native Android / iOS builds.

🔗

Share to WhatsApp

Every debate has a share endpoint (/api/v1/topic/:id/share) that generates server-rendered Open Graph preview cards — so debates look great when shared on WhatsApp, Twitter, or Telegram.
